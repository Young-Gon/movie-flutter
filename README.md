# movie

영화 정보를 보여주는 Flutter 앱입니다
Movie, TV, Search 세개의 탭을 가지고있는 HomeScreen과 상세화면을 보여주는 DetailScreen으로 구성되어 있는 간단한 앱입니다
화면 레이아웃 구성 및 네비게이션, API 통신, 데이터 파싱과 모델 상속, reverpod으로 관리되는 api 상태관리와 케싱 기능을 보실 수 있습니다
